Privacy Policy

Last updated:

This policy describes what data MinesweeperOnline collects, why, and how it is handled.

Username

You may optionally choose a username when using the app. A real name is not required — any name or alias you prefer is accepted. The username is stored on our server solely so that your friends can recognize you in the game and so that you can appear on the leaderboard under the name of your choosing.

Platform identifier

The app reports a compile-time constant to the server indicating which version you are running: Web, Linux, Windows, or Android. This value is fixed at build time and contains no device-specific or user-specific information.

Chat messages

The app includes an optional in-game chat feature. Any messages you send are received by the server. Chat is not required for the game to function — you are free to ignore it entirely. If you do not send any messages, no chat data is collected.

Data sharing

Nothing is shared with any third party. All data — usernames, platform identifiers, and chat messages — remains exclusively on our server and is not sold, transferred, or disclosed to anyone.
